# Visão geral do projeto

## 1. Apresentação

O Mini RPG Java é um jogo de fantasia medieval executado no terminal. O jogador controla um aventureiro e enfrenta inimigos em combates por turnos.

O desenvolvimento acontece de forma incremental, com cada etapa acrescentando novas funcionalidades e permitindo praticar conceitos de programação.

## 2. Objetivo

Desenvolver um jogo em Java que permita ao jogador participar de batalhas, escolher ações e acompanhar os resultados dos combates.

O projeto também tem como finalidade consolidar conhecimentos de lógica de programação e criar um projeto pessoal para o GitHub.

## 3. Objetivos de aprendizagem

- Praticar estruturas condicionais.
- Utilizar estruturas de repetição.
- Desenvolver métodos com parâmetros e retorno.
- Trabalhar com variáveis e atualização de valores.
- Gerar números aleatórios.
- Organizar regras e comportamentos de uma aplicação.
- Aprender a testar funcionalidades.

## 4. Escopo inicial

A primeira versão prevê uma batalha entre um aventureiro e um Goblin.

O jogador terá pontos de vida e poções de cura. Durante o combate, poderá atacar, recuperar vida ou fugir.

## 5. Tecnologias

- Linguagem Java.
- `Scanner` para entrada de dados.
- Terminal para interação com o jogador.

## 6. Estado atual

O protótipo já permite informar o nome do aventureiro, inicializar os atributos, exibir as fichas dos personagens e selecionar opções por meio de um menu com `switch`.

As mecânicas efetivas de combate ainda estão em desenvolvimento.
