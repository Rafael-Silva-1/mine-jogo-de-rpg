# Requisitos do projeto

## 1. Requisitos funcionais da v1.0.0

| Código | Requisito | Situação |
|---|---|---|
| RF01 | Solicitar o nome do aventureiro | Implementado |
| RF02 | Inicializar o aventureiro com 100 HP e duas poções | Implementado |
| RF03 | Criar o Goblin com 80 HP | Implementado |
| RF04 | Exibir as fichas dos personagens | Implementado |
| RF05 | Exibir o menu de ações | Implementado |
| RF06 | Tratar as opções usando `switch` | Implementado |
| RF07 | Aplicar dano aleatório ao Goblin | Pendente |
| RF08 | Realizar contra-ataque do Goblin | Pendente |
| RF09 | Recuperar vida usando poções | Pendente |
| RF10 | Permitir fugir da batalha | Pendente |
| RF11 | Identificar vitória ou derrota | Pendente |
| RF12 | Repetir turnos até o fim da batalha | Pendente |
| RF13 | Permitir iniciar uma nova partida | Pendente |
| RF14 | Tratar escolhas inválidas durante o combate | Parcialmente implementado |

## 2. Requisitos não funcionais

- O jogo deve ser executado no terminal.
- O código deve permanecer legível e organizado.
- As funcionalidades devem ser desenvolvidas gradualmente.
- Os resultados devem ser conferidos por meio de testes.
- A documentação deve refletir o estado real do projeto.

## 3. Limites da primeira versão

A v1.0.0 não exige interface gráfica, banco de dados, conexão com a internet ou sistema de salvamento.

O foco é desenvolver a lógica de um combate funcional utilizando recursos básicos de Java.
