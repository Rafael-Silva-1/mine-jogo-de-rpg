# Plano de versões

Este documento registra a evolução planejada do Mini RPG Java. As funcionalidades futuras poderão ser ajustadas conforme o aprendizado e as necessidades do projeto.

## v1.0.0 — Primeira batalha

**Objetivo:** criar um combate funcional entre o aventureiro e o Goblin.

- [x] Criar os personagens e definir seus atributos iniciais.
- [x] Exibir as fichas.
- [x] Criar o menu de ações.
- [x] Tratar as opções com `switch`.
- [ ] Implementar o ataque com dano aleatório.
- [ ] Implementar o contra-ataque.
- [ ] Implementar cura e consumo de poções.
- [ ] Implementar a fuga.
- [ ] Controlar a repetição dos turnos.
- [ ] Identificar vitória e derrota.
- [ ] Permitir jogar novamente.
- [ ] Concluir os testes da versão.

## v1.1.0 — Melhorias no combate

Possíveis ajustes no fluxo dos turnos, nas mensagens e na experiência de jogo.

## v1.2.0 — Organização com métodos

Separar responsabilidades em métodos, praticando parâmetros, retornos e reutilização de código.

## v1.3.0 — Progressão do personagem

Explorar novas mecânicas, como moedas, experiência e evolução do aventureiro.

## v2.0.0 — Evolução com orientação a objetos

Avaliar a criação de classes específicas para personagens, inimigos e combate após consolidar os fundamentos de POO.

> As versões futuras são propostas de planejamento. Uma funcionalidade só deverá ser marcada como concluída depois de implementada e testada.
